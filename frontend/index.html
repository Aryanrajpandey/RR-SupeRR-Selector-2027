Behind the score

A transparent, delivery-level model developed for the SupeRR Selector Round 1 report.

01 / CLEAN

Audit the ball-by-ball data

Combine six competition files. Exclude 64 abandoned, no-result or revised fixtures; retain innings 1–2.

02 / LABEL

Define pre-ball pressure

Flag collapses, death overs, chase squeezes, close finishes and knockouts using the state before each ball.

03 / SCORE

Compare like with like

Adjust for format, innings, phase and pressure. Combine run impact and wicket equivalents against contextual peer averages.

04 / VALIDATE

Reward repeatability

Apply exposure thresholds, consistency, sample shrinkage, 750 match-cluster bootstrap replicates and sensitivity checks.

Score design

Final score = [0.85 × P + 0.15 × (P − O)] × N/(N + 180) + 8 × [(positive matches + 6)/(qualifying matches + 12) − 0.5]

P = weighted contextual pressure value per 100 balls; O = weighted ordinary value per 100 balls; N = effective weighted pressure-ball exposure. Wickets carry an assumed 7.5-run equivalent. Eligible candidates had ≥20 pressure matches, ≥120 pressure balls, ≥150 ordinary balls, representation in ≥2 seasons and ≥8 qualifying pressure matches.

Important limitations: The supplied dataset spans IPL 2022–2026, T20 internationals and Emerging/Asia Cup T20 events, not only domestic leagues. Player availability, retention, IPL eligibility, injuries, salaries and auction price were not verified in the dataset. Abrar Ahmed and Mohammad Nawaz have zero IPL pressure balls in this pack. Model uncertainty intervals overlap, so the exact order should not be treated as certain.
